RepairBuddy
This is a Next.js project bootstrapped with create-next-app.

RepairBuddy is a platform for vehicle and motorcycle repair guides with dynamic search and user authentication.

Getting Started
First, run the development server:

bash
Copy
Edit
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
Open http://localhost:3000 with your browser to see the result.

You can start editing the project by modifying app/page.tsx and other components under src/components/ui. The page auto-updates as you edit the files.

This project uses next/font to automatically optimize and load custom fonts.

Features
Dynamic motorcycle search by year, make, and model

Authentication modals (Login and Signup) powered by Supabase

Responsive UI with modern styling and modal popups

User session handling to persist login state
